# ARENA X

Платформа для организации локальных киберспортивных турниров: игроки, команды, заявки, расписание, сетки и результаты.

## Технологии

- Laravel 12 / PHP 8.2+
- Blade, HTML5, CSS3, JavaScript, Vite
- SQLite для локальной разработки
- PostgreSQL / Supabase для общей базы данных
- GitHub Actions для автоматической проверки сборки и тестов

## Локальный запуск на macOS

Установите инструменты:

\`\`\`bash
brew install php composer node
\`\`\`

Клонируйте репозиторий:

\`\`\`bash
git clone https://github.com/levpalch9-lang/arena-x.git
cd arena-x
\`\`\`

Установите зависимости, подготовьте SQLite, загрузите демонстрационные данные и соберите frontend:

\`\`\`bash
composer run setup
\`\`\`

Запустите приложение:

\`\`\`bash
php artisan serve
\`\`\`

Адрес: http://127.0.0.1:8000

- Главная: \`/\`
- Каталог: \`/tournaments\`
- Вход: \`/login\`
- Регистрация: \`/register\`
- Настройки профиля после входа: \`/profile\`
- Панель администратора: \`/admin\`

## Supabase PostgreSQL

Проект Supabase \`arena-x\` уже создан. Существующая схема содержит таблицы \`users\`, \`games\`, \`teams\`, \`team_members\`, \`tournaments\`, \`registrations\`, \`matches\`, \`notifications\`, а также таблицы Laravel для сессий и сброса пароля.

Для подключения Laravel использует прямое серверное соединение PostgreSQL. Шаблон параметров находится в \`deployment/supabase-db.env.example\`, подробные шаги — в \`deployment/README.md\`.

Пароль базы данных хранится только в локальном \`.env\`. Не помещайте его в GitHub, HTML, JavaScript или Vite-переменные. Не используйте \`service_role\` / secret key в браузере.

Базовая Laravel-миграция проверяет существующие таблицы и не пересоздаёт схему Supabase. Для применения миграций используйте \`php artisan migrate --force\`. Никогда не запускайте \`php artisan migrate:fresh\` на общей базе: команда удаляет таблицы и данные.

## Реализованные модули

- Публичная главная страница с реальными турнирами, дисциплинами, расписанием и статистикой.
- Каталог турниров с поиском и фильтрами по игре, статусу и дате.
- Страница турнира: правила, параметры, участники, таблица, сетка, расписание и результаты.
- Регистрация, авторизация, выход, хеширование паролей и ограничение частоты входа.
- Редактирование профиля, email и игрового никнейма; смена пароля с проверкой текущего.
- Роли гостя, игрока, капитана, организатора и администратора с серверной проверкой доступа.
- Создание команд, назначение капитана, добавление и удаление участников.
- Создание, публикация и изменение статусов турниров.
- Командные и индивидуальные заявки с проверкой повторов, сроков и лимита мест.
- Модерация заявок организатором и администратором.
- Создание матчей, расписание, карты, ввод счёта, определение победителя и продвижение по сетке.
- Турнирные таблицы и уведомления.
- Административный центр: статистика, поиск пользователей, изменение ролей, список турниров и модерация.

## Проверка

GitHub Actions выполняет установку PHP/Node-зависимостей, production-сборку Vite и PHPUnit-тесты. Последняя проверенная сборка на момент обновления README: 34 теста, 109 утверждений — успешно. Более свежие изменения также проходят CI отдельно; статус см. во вкладке Actions репозитория.

## Публичное развёртывание

Для публичного запуска дополнительно нужны хостинг с PHP 8.2+ и поддержкой Laravel 12, HTTPS и переменные окружения приложения. Публичный хостинг пока не настроен в репозитории. Не публикуйте сайт с \`APP_DEBUG=true\` или демонстрационными паролями.
