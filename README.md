# ARENA X

Платформа для проведения локальных киберспортивных турниров.

## Технологии
- Laravel 12 / PHP 8.2+
- Blade, Vite, CSS
- SQLite для автономной локальной демонстрации
- PostgreSQL / Supabase как удалённая БД

## Быстрый запуск на MacBook (macOS)

Откройте Terminal. Установите инструменты:

```bash
brew install php composer node
```

Скачайте проект:

```bash
git clone https://github.com/levpalch9-lang/arena-x.git
cd arena-x
```

Установите зависимости, создайте локальную БД, загрузите демонстрационные данные и соберите интерфейс:

```bash
composer run setup
```

Запустите сайт:

```bash
php artisan serve
```

Откройте http://127.0.0.1:8000.

Каталог турниров: http://127.0.0.1:8000/tournaments
Вход: http://127.0.0.1:8000/login
Регистрация: http://127.0.0.1:8000/register

## Supabase

Схема проекта Supabase уже существует отдельно и содержит таблицы пользователей, игр, команд, участников, турниров, заявок, матчей и уведомлений. Для подключения вместо SQLite укажите в локальном `.env` параметры PostgreSQL: `DB_CONNECTION=pgsql`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`, `DB_SSLMODE=require`.

Не публикуйте файл `.env`, пароль базы или секретные ключи. Для уже созданной базы Supabase не запускайте повторно миграцию создания таблиц; локальная миграция нужна для автономной SQLite-демонстрации.

## Текущий функционал

- Главная страница, каталог и подробная страница турнира.
- Регистрация игрока, вход, выход и личный кабинет с отображением роли.
- Пароли хранятся в виде хешей; вход и регистрация ограничены по частоте.
- Создание команд, назначение капитана и просмотр своих команд.
- Подача командных заявок с проверкой срока, лимита мест и повторных заявок.
- Кабинет организатора: создание турниров, просмотр и принятие/отклонение заявок.
- Панель администратора со сводной статистикой и последними пользователями/турнирами.
- Демонстрационные профили с ролями игрока, капитана, организатора и администратора.
- Модели и миграции для игр, команд, заявок, турниров, матчей и уведомлений.

## Статус

Проект проходит CI-сборку в GitHub Actions. Полный рабочий цикл команд, заявок, создания турниров, результатов матчей и административной модерации ещё реализуется. Перед публичным запуском необходимо настроить защищённую авторизацию и политики доступа для выбранного окружения.
