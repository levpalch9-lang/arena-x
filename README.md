# ARENA X

Платформа для проведения локальных киберспортивных турниров.

## Технологии
- Laravel 12 / PHP 8.2+
- Blade, Vite, CSS
- PostgreSQL (Supabase-compatible)

## Запуск на MacBook (macOS)

Откройте Terminal. Если Homebrew ещё не установлен, установите его с официального сайта https://brew.sh. Затем выполните:

```bash
brew install php composer node
```

Скачайте проект и перейдите в папку:

```bash
git clone https://github.com/levpalch9-lang/arena-x.git
cd arena-x
```

Установите зависимости и подготовьте приложение:

```bash
composer install
cp .env.example .env
php artisan key:generate
npm install
npm run build
php artisan serve
```

Откройте http://127.0.0.1:8000.

## База данных Supabase

Структура базы ARENA X уже создана в отдельном проекте Supabase. Для подключения заполните в локальном `.env` параметры PostgreSQL: `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`. Не публикуйте этот файл, пароль базы или секретные ключи. Файл `.env` исключён из Git.

До заполнения параметров база не используется главной демонстрационной страницей: сессии и кеш работают через локальные файлы. Не запускайте миграции на общей базе без предварительной проверки схемы.

## Роли и предметная область

Планируемые роли: игрок, капитан, организатор и администратор. В базе предусмотрены пользователи, игры, команды, участники команд, турниры, заявки, матчи и уведомления.

## Статус реализации

В репозитории находится начальный Laravel 12 каркас, стартовая страница, конфигурация PostgreSQL, Eloquent-модели основных сущностей и smoke-test главной страницы. Подключение к реальной базе из Laravel, авторизация, CRUD-операции и полный игровой/турнирный цикл ещё требуют реализации и проверки. GitHub Actions выполняет проверку сборки и тестов.
